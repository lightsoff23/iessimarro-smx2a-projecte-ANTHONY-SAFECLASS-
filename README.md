(SAFECLASS) — Projecte Intermodular SMX 





El projecte busca millorar la seguretat informàtica d'un xicotet col·legi, que necessita protegir els seus ordinadors, les xarxes i les dades d'alumnes i professors. Es proposa separar les xarxes, actualitzar el programari i aplicar mesures bàsiques de ciberseguretat.

Rols simulats



\- Rol A — Coordinació del projecte i documentació.

\- Rol B — Configuració de xarxes i dispositius.

\- Rol C — Ciberseguretat, actualitzacions i proves.



&#x20;Contingut del repositori



\- `documents/` — Document de Repte (Annex A).

\- `documents/fitxes/` — Fitxes d'activitat (Annex B).

\- `configuracio/` — Configuracions tècniques de xarxa i seguretat.
